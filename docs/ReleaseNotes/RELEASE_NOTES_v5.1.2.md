# LastEpoch HUD v5.1.2

Compatibility update for the November 25 Last Epoch Steam build `26470811` (Unity 6000.4.8) and MelonLoader 0.7.3 Open-Beta. Press F3 in a zone to open the mod menu.

## Changelog

### Fixes

- Updated the patched `UnityEngine.CoreModule.dll` for the latest Last Epoch `GameAssembly.dll`, fixing the native startup crash before MelonLoader could initialize its support module.
- Rebuilt and validated the HUD against the current game interop assemblies.

This release contains no gameplay feature changes.

## Install

- Install steps are in the repository [README](https://github.com/Syncingoutt/LastEpoch_Mods/blob/master/README.md).
- Alternatively, use the [LE Hud Installer](https://github.com/TriSSec-Lab/LE-Hud-Installer) to install the mod automatically.
